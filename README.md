## ✨ Features & Highlights

- 💎 **Premium Glassmorphism UI**: Backdrop blur surfaces, ambient glow orbs, subtle borders, and smooth transitions.
- 🌓 **Dark / Light Theme Toggle**: Persistent theme switching with customized glass styling for both modes.
- ⚡ **Hero with Animated Developer Terminal**: Dynamic typing subtitle, floating tech chips (Java, Python, C, React, AI, Data), and direct CTAs.
- 🎓 **Education Timeline**: Detailed milestones for **KL University (9.6 CGPA)**, **Narayana Junior College (89%)**, and **Little Flower High School (9.7 CGPA)**.
- 📜 **Verified Certifications Showcase**:
  - *Building Agentic AI Applications with Large Language Models* — **NVIDIA**
  - *Data Analytics Job Simulation* — **Deloitte / Forage**
  - *Introduction to Generative AI Studio* — **Google Cloud / GenAI**
  - *ReactJS for Beginners* — **Frontend Certified**
- 🛠️ **Interactive Skills Matrix**: Filterable and searchable skills with proficiency visualizers.
- 💼 **Categorized Projects Showcase**: Filter by `Web`, `AI`, `Data`, `Other` with live preview modals and repository links.
- 🏆 **Achievements & Highlights**: Academic consistency, AI/Data learning, frontend engineering, and hackathon participation.
- 📬 **Interactive Contact Section**: Form validation, instant feedback, celebratory confetti, and mailto fallback.
- 📄 **Interactive Resume Viewer**: One-click printable and downloadable PDF resume modal.

- **Animations**: CSS Keyframes + Framer Motion & [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Deployment**: GitHub Pages / Vercel / Netlify ready

## 🚀 Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/raskassaikarthik07-droid/The_Comeback-79.git
   cd The_Comeback-79
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
